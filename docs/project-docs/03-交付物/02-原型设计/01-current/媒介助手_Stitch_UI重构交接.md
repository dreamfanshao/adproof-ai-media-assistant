## 视觉决策

- 画布：暖纸白 `#F7F7F4`，减少长时间操作的视觉疲劳。
- 导航：深墨色 `#1D2433`，保持工作区与本地 Eval 的产品识别度。
- 主色：靛蓝 `#5B5CE2`，用于主操作、已验证和当前步骤。
- 提醒色：琥珀 `#F3B562`，用于需人工复核；红色只表示高风险。
- 字体：Plus Jakarta Sans（标题）+ Inter（正文/数据）。
- 结构：高信息密度、细分隔线、低阴影，不使用营销型渐变。
