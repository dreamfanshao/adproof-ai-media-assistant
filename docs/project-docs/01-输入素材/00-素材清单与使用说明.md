## 素材效力顺序

发生内容冲突时，按以下原则处理：

1. 用户在当前会话中的明确指令；
2. 官方现行法律法规原文；
3. 最新未被替代的已确认项目决策和当前 PRD；
4. 用户上传且已标明来源、版本和适用范围的私有规则；
5. 未经验证的模型判断和推断。

## 长文件读取约定

- 大文件按条款、章节、页次或时间戳定位读取。
- 新素材入库时同步登记来源、用途、版本和效力。
- 法规原文与从原文提炼的审核规则分开保存，并保持引用关系。
- 测试数据必须脱敏；账号密码、Cookie、Token、验证码和 API Key 禁止入库。
