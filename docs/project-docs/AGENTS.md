# AGENTS.md

「媒介助手」资料工作区入口。细则与当前阶段见 `99-工作区索引.md`。

## 项目信息

- **目标**：在 7 天内完成面向小红书媒介专员的验证型 MVP，通过自然语言筛选素人达人，并利用广告法公共知识库和用户私有知识库辅助审核图文内容。
- **交付物**：产品文档、原型设计、技术文档、测试与验收、部署与使用说明。
- **输入**：已确认的 MVP PRD；达人样本、私有规则文档和标注测试数据待开发测试阶段补充。
- **上游**：当前无跨工作区依赖。
- **红线**：不得存放账号密码、Cookie、Token、验证码或密钥；不得用静态数据冒充实时小红书结果；不得把 AI 审核结果表述为法律结论。

## 流转关系

```text
输入 ──► 任务包 ──► 分析（可选）──► 交付物
  │         │                         │
  │         ├─ 过程 / 证据留在任务包    ├─ 仅用户确认后进 01-current
  │         └─ 完成整包 → 99-done      └─ 旧版 → 99-history
  │
  └─ 素材清单登记；跨工作区只引用不复制

管理：工作台（当前唯一任务）· 决策账本（只追加）· 工作日志（当日事实）
```

| 分区 | 放什么 | 流转 |
| --- | --- | --- |
| `01-输入素材/` | 用户素材、法规规则、脱敏测试数据 | 只作为工作依据，不直接成为交付物 |
| `02-任务/01-current/` | 唯一当前任务包 | 完成确认后整体进入 `99-done/` |
| `04-分析/` | 调研、诊断、架构和 Eval 分析 | 当前结论进 `01-current/`，旧版进 `99-history/` |
| `03-交付物/01-产品文档/` | PRD、流程和需求说明 | 确认后进 current，旧版进 history |
| `03-交付物/02-原型设计/` | 用户流程、线框和高保真原型说明 | 确认后进 current，旧版进 history |
| `03-交付物/03-技术文档/` | 架构、接口、数据模型和实现说明 | 确认后进 current，旧版进 history |
| `03-交付物/04-测试与验收/` | 本地 Eval 方案、测试报告和验收记录 | 确认后进 current，旧版进 history |
| `03-交付物/05-部署与使用说明/` | 部署方案和用户操作说明 | 确认后进 current，旧版进 history |
| `00-工作台/` | 当前状态和决策账本 | 状态随任务更新；决定只追加 |
| `09-工作日志/` | 当日实际完成事项 | 不替代任务状态、决定或成果 |
