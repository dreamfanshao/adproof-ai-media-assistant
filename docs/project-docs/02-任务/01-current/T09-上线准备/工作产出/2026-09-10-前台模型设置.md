# 前台模型设置实施记录

## 交付范围

- 主系统侧栏底部新增“模型与 API Key”入口，采用与“更换数据源 Key”一致的弹窗交互，不新增独立菜单和页面。
- 支持按服务商录入/更换 API Key、刷新模型列表、测试连接、保存并启用。
- 弹窗沿用现有蓝白主题、卡片与状态色规范，提供桌面与移动端响应式布局。
- 每个用户的模型设置独立；各服务商 Key 可分别保留，只允许一个当前模型。

## 安全与运行

- API Key 使用 AES-256-GCM 加密，AAD 同时绑定用户 ID 与服务商；接口只返回不可逆短指纹。
- API Key 不写入浏览器持久化、任务 payload、任务结果或日志。
- Base URL 由后端服务商目录固定，避免自定义地址造成 SSRF。
- Worker 在领取任务时解析当前用户模型，通过 AsyncLocalStorage 绑定到该任务；并发上下文不会串 Key。
- Claude 使用原生 Messages API；其余服务商使用官方 OpenAI 兼容对话接口。
- GLM 暂无账号级模型列表接口，刷新使用后端维护的官方目录，连接测试调用所选模型验证。
- Eval 仍保持本地运行，不读取线上用户模型设置。

## 数据库与发布

- 新增迁移：`supabase/migrations/202609100001_user_model_settings.sql`。
- 表位于 `private` schema，撤销 `anon`/`authenticated` 权限，仅可信 API 与 Worker 数据库直连。
- 迁移未应用时，前端显示明确阻断信息；Worker 自动回退到原环境变量模型配置，不影响现有任务。
- 已向当前 `DATABASE_URL` 指向的数据库应用迁移，并验证表已存在且 `anon`/`authenticated` 均无直接查询权限。
- 新增显式迁移检查工具 `scripts/apply-model-settings-migration.mjs`；未部署 ECS、未修改 `.env` 或任何真实密钥。
