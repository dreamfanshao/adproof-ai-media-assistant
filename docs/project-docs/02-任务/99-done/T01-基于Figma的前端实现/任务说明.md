# T01｜基于 Figma 的前端实现

## 任务目标

以 Figma 文件 `媒介助手｜高保真原型` 中 `Core Screens` 的最新 UI 为唯一视觉基准，完成媒介助手 MVP 的可运行前端。

## 范围

- 建立 React、TypeScript 与 Vite 工程。
- 落地 Figma 的颜色、字体、圆角、间距、侧栏和顶栏规范。
- 实现登录、扫码连接、工作台、达人检索、达人状态管理、内容审核、审核记录和知识库页面。
- 使用明确标识的演示数据验证前端流程，不冒充实时小红书数据。
- 完成构建、类型检查和本地服务响应验证。

## 不在本任务范围

- 真实账号认证与用户隔离。
- 小红书扫码会话和实时数据链路。
- OpenAI、OCR、RAG 和文件存储后端。
- 生产部署。

## 验收条件

- `npm run build` 与 `npm run typecheck` 通过。
- 10 个页面路由可被开发服务器返回。
- 达人状态互转、筛选、导出、审核提交和知识库创建具备前端交互。
- 页面中明确提示当前数据属于演示模式。
