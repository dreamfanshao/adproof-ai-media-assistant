## 1.6 受控浏览器窗口彻底隐藏（2026-08-18 ✅）

- 问题：有头 Edge 即使 `--start-minimized` + `--window-position=-32000`，仍会在屏幕/任务栏闪现（CDP `setWindowBounds("normal")` 还会取消最小化）。
- 结论：headless 不可行（小红书风控 300012 直接拦截），必须保持有头模式。
- 修复：浏览器级 CDP `SystemInfo.getProcessInfo` 取浏览器主进程 PID → user32 `ShowWindow(SW_HIDE)` 彻底隐藏（任务栏也不出现）；启动前先跑隐藏监控（按 `playwright_chromiumdev_profile` 临时配置目录匹配），窗口创建瞬间即隐藏；移除 create/restore 中会取消最小化的 CDP 定位调用。
- 实测：create() 全流程 100ms 采样 40 次，窗口从未出现（`MainWindowHandle` 恒为 0）；二维码抓取 2/2 成功。
- 验证窗口：仅当风控时用户点击"打开验证窗口"才 `SW_SHOW` 临时显示。
- 附带加固：`openLoginPanel` 增加二维码等待、Esc 关闭遮罩、回车/点击重试，解决"弹窗遮罩拦截点击"偶发失败。
- 新增退出入口：找达人页连接后显示"退出小红书"按钮（DELETE 连接 + 清 `platform_sessions`），退出后下次检索需重新扫码。

## 2. 首次检索扫码

1. 浏览器打开 `http://127.0.0.1:5173`，登录媒介助手（邮箱+密码）。
2. 进入"找达人" → 点击"开始检索" → 应跳转 `/connect?returnTo=/creators`（会话检查：GET 连接状态 ≠ connected）。
3. 连接页显示二维码（二维码直显当前页；受控 Edge 窗口在屏幕外）→ 用户用小红书 App 扫码 → 状态流转 `qr_pending → qr_scanned → connected` → 自动返回找达人页。
4. 记录：`platform_sessions` 出现该用户行（含 `encrypted_state/nonce/tag`），`message_code = XHS_CONNECTED`。

## 3. 服务重启后免扫码（关键断言）

1. 杀掉 API 进程并重启（模拟服务重启）。
2. 回到找达人页 → "开始检索" → **不应出现二维码**，连接状态应为 `connected`（`XHS_CONNECTED_RESTORED`）。
   - 说明：`get()` 从 `platform_sessions` 读取并解密 storageState，restore 校验 `web_session` Cookie 有效后恢复 LiveSession。
3. 重新登录媒介助手（退出 → 登录）→ 再点"开始检索" → 仍免扫码。

## 4. 过期补扫

1. 手工将 `session_expires_at` 置为过去（或等 8h TTL 到期）→ 再次"开始检索" → 应回到连接页补扫二维码，扫码成功后继续原检索。

## 5. 失败路径（如遇）

- restore 失败（Cookie 失效/风控文本）→ 状态置 `expired`（`XHS_SESSION_EXPIRED`），清空 `session_expires_at`，前端进入补扫。
- 触发平台安全验证 → `restricted`，弹出 Edge 窗口人工验证后回当前页。
