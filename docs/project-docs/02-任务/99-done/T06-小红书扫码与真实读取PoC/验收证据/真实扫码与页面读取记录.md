## 当前边界

1. 仅完成一次人工扫码、一次搜索页和一个达人主页的成功链路，尚未验证长时间稳定性、批量翻页和频控阈值。

3. 当前不会持久化会话。连接 API 接入前需先实现服务端加密存储、过期清理和主动断开。
4. 页面 DOM 与平台策略可能变化，需要选择器版本管理、失败分类和低频重试；不得自动绕过验证码或风控。
5. 本结果证明技术链路在本次环境可行，不等于平台官方授权，也不构成生产可用性结论。

# 附录：连接服务产品化与会话恢复验证记录（2026-08-18）

## 环境与配置

- API `http://127.0.0.1:3001`（Fastify + Playwright 受控 Edge），前端 `http://127.0.0.1:5173`。
- `.env.local` 成对配置 `SUPABASE_SERVICE_ROLE_KEY` + `XHS_SESSION_ENCRYPTION_KEY`（32 字节），`platform_sessions` 持久化启用。
- 服务端自检：`test:server` 14/14、typecheck 通过；健康检查 200；Vite 代理链路 200。

## 2026-08-18 服务端预验证（临时测试用户，已清理）

- `/api/v1/me` + 真实 Supabase JWT → 200（API 与 Supabase 真实连通）。
- POST 连接 → 201 `qr_pending` + 真实二维码；`platform_sessions` 出现该用户行。
- 无人工介入的全新自动化会话被风控 → 状态自动流转 `restricted`（`XHS_PLATFORM_RESTRICTED`）——状态机按设计工作。
- DELETE 连接 → 204；临时用户与 `platform_sessions` 归零。

## 受控浏览器窗口彻底隐藏（实测）

- headless 模式被小红书风控拦截（300012"IP存在风险"），确认必须保持有头模式。
- 修复：`--start-minimized` + 离屏定位 + 浏览器级 CDP `SystemInfo.getProcessInfo` 取主进程 PID + user32 `ShowWindow(SW_HIDE)`，启动前先跑隐藏监控（按 `playwright_chromiumdev_profile` 临时配置目录匹配）。
- 实测：create() 全流程 100ms 采样 40 次，受控 Edge 窗口从未出现（`MainWindowHandle` 恒为 0）；屏幕与任务栏均不可见；仅用户主动"打开验证窗口"时临时显示。
- 二维码抓取稳定性：加固 `openLoginPanel`（Esc 关遮罩、回车/点击重试）后连测 2/2 成功。

## 用户真实扫码验证（四步闭环，2026-08-18）

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 首次/补扫扫码 | 会话过期状态下点"开始检索" → 弹出二维码 → 小红书 App 扫码 | 通过：`qr_pending → qr_scanned → connected`，自动继续检索；`platform_sessions` 写入 `XHS_CONNECTED` |
| 服务重启免扫码 | 杀掉并重启 API 进程后再次"开始检索" | 通过：从 `platform_sessions` 解密恢复 storageState，无二维码直接出结果；右上角头像恢复显示 |
| 重新登录免扫码 | 退出/重登媒介助手后再检索（设计内，本轮由用户确认 §3 时验证） | 通过 |
| 过期补扫 | 将 `session_expires_at` 置为过去并重启 API → 再次"开始检索" | 通过：恢复检查后判定过期 → 自动回到二维码补扫，扫码成功后继续检索 |

- 前端体验：二维码生成已异步化——POST 秒回（实测 35–48ms），弹窗立即显示"正在生成二维码…"，就绪后轮询展示；捕获上限 12s 兜底。
- 退出能力：连接后右上角显示小红书头像，点头像确认后 DELETE 连接并清除持久化会话，下次检索重新扫码。
- 凭据安全：全程未在文档、日志或验收证据中输出 Cookie、Token、二维码内容或完整账号标识；storageState 仅以 AES-256-GCM 密文落库。

## 仍属边界的项目

1. 单用户单会话验证；并发用户、频控阈值、批量翻页与长时间稳定性未验证。
2. 头像抓取为多选择器 best-effort，页面结构变化时可能回退为默认图标（不影响连接）。
3. 平台风控行为可变（本轮曾出现 `restricted`），验证窗口机制可用但未做自动化回归。
4. 本结论不构成平台官方授权或生产稳定性承诺。
