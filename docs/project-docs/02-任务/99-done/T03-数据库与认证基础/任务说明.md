## 任务目标

产出可用于新建 Supabase 项目的数据库模型、Migration、RLS、Storage 权限和双用户隔离测试方案，为后续 Fastify API 与小红书 PoC 提供数据基础。

## 本期范围

1. 核心业务表、枚举、唯一约束、外键和索引。
2. Supabase Auth 用户资料触发器。
3. 公共广告法库与用户私有数据的 RLS。
4. `private.jobs`、任务事件和上传意图的服务端边界。
5. 私有 Storage Bucket 与对象访问策略。
6. 用户 A / 用户 B 越权测试矩阵。

## 不在本任务执行

- 不连接或修改真实 Supabase 项目。
- 不创建、写入或展示 API Key、service role key、Cookie 或 Token。
- 不导入广告法正文。
- 不实现 Fastify 路由或小红书浏览器连接器。
- Embedding 维度未确认前不创建向量 ANN 索引；MVP 小数据量先允许顺序检索。

## 验收标准

- 数据模型与已确认 OpenAPI 字段和状态一致。
- 所有用户私有数据能由 `user_id` 追溯并启用 RLS。
- 公共广告法只读，私有知识库不能跨用户读取。
- Worker/service role 边界明确，浏览器不能访问 `private` Schema。
- Migration 可以从空库按顺序执行，并具备回归检查方案。
