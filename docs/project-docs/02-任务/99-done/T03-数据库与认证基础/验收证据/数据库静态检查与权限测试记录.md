## 2. 独立读者测试发现与修复

首轮读者测试判定存在一个严重并发风险和若干契约/隔离缺口，已完成以下修复：

1. Job 增加递增 `lease_version`；新增租约锁定、续租、原子状态迁移与事件追加函数。
2. Worker 在业务结果写入事务中必须先校验 `job_id + worker_id + lease_version + 未过期租约`，过期 Worker 被 fencing。
3. claim 不再把 `stage` 改成契约外的 `running`。
4. 每用户最多一个运行中的 `knowledge_ingest` Job，由部分唯一索引防并发竞态。
5. 公共广告法文档允许 `task_id=null`；私有文档提交响应仍要求非空任务 ID。
6. 审核快照创建后不可更新，浏览器无删除权限；父资源清理仍可级联删除。Finding 必须引用快照内的具体文档版本和对应 chunk。
7. Storage INSERT 同时校验用户目录和未过期 upload intent，不能绕过 API 任意直传。
8. `project_creators.search_task_id` 通过三列复合外键绑定同一用户、同一项目。
9. 项目创建幂等键持久化到 `projects` 并受用户级唯一约束保护。
10. 双用户测试模板增加跨租户 INSERT/UPDATE、公共广告法只读、审核隔离、Storage 隔离和敏感表拒绝检查。

第二轮独立读者复查结论：上述高风险项均已关闭，未发现阻止进入用户评审的静态问题；完整真实环境验收仍以后续空库执行结果为准。
