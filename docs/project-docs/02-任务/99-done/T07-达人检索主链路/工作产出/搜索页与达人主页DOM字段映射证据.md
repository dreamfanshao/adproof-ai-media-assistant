# T07 Phase 1｜搜索页与达人主页 DOM 字段映射证据

> 日期：2026-08-18  
> 数据源：用户真实小红书会话（platform_sessions 解密恢复，隐藏 Edge），关键词"光子嫩肤"  
> 用途：字段映射模块的选择器基线；页面结构变化时以此为准做失败分类  
> 脱敏：昵称保留展示（公开数据）；主页链接、头像 URL 截断；不输出任何 Cookie/Token/凭据

## 1. 搜索页（/search_result?keyword=…&source=web_explore_feed）

- 状态：真实会话可读，无风控；识别 `a[href*="/user/profile/"]` 44 个、`a.author[href*="/user/profile/"]` 40 个。
- 卡片容器：`.note-item`；作者链接：`a.author[href*="/user/profile/"]`。
- 卡片文本示例（含笔记标题、作者昵称、日期、点赞数）：
  `水光针和光子怎么选？很简单，一张图教会你 八大处整形医生周经 04-03 2108`
- 注意：结果第一张是当前登录用户自己的"我"卡片（`popover-container`，文本"我我"），收集时须跳过。
- 卡片封面图：`img[src*="sns-webpic-qc.xhscdn.com"]`（笔记封面，非作者头像）。

## 2. 达人主页（/user/profile/{userId}）

- 状态：真实会话可读，无风控；内容异步加载，需等待 `.user-nickname`/`.user-name` 出现（或轮询指标文案）。
- 字段选择器（实测有效）：

| MVP 字段 | 选择器 / 定位 | 实测示例（脱敏） |
| --- | --- | --- |
| 昵称 | `.user-nickname` 或 `.user-name` 文本 | 厦门中医院皮肤科刘医生 |
| 关注数 | `.shows` 元素文本"NN关注" | 62 关注 |
| 粉丝数 | `.shows` 元素文本"NN粉丝" | 193 粉丝 |

| 小红书号 | 正文"小红书号：XXXX" | 661343176 |
| IP属地 | 正文"IP属地：X" | 福建 |
| 简介 | 昵称区下方段落（正文位于指标前） | 厦门公立三甲医院皮肤科医师…随缘回复 |
| 头像 | `img[src*="sns-avatar-qc.xhscdn.com/avatar/"]`（首张，非页脚 logo） | 截断不录 |
| 笔记列表 | 正文中"笔记"区：标题 + 点赞/互动数 | 标题…+ 数字 |

- 主页正文结构（innerText 顺序）：导航 → 页脚备案信息（前部）→ 用户信息（昵称/小红书号/IP属地/简介/指标）→ 笔记列表。**不能按 innerText 前 600 字截取**；应直接用选择器抓取，或定位到 `.user-nickname` 后取其后文本块。

## 3. 收集与映射建议

1. 搜索页：按页滚动/翻页收集 `a.author` 链接去重（跳过"我"卡片）→ 得到平台达人 ID（href 末段）与昵称（卡片文本中作者段）。
2. 主页：逐一打开（限速 + 失败分类），抓 `.user-nickname`/`.shows`/简介/头像；字段缺失记 `field_warnings`，`data_completeness=partial`。
3. 笔记列表首屏标题 + 互动数可作为语义匹配输入（后续 Phase 2）。
4. 选择器版本管理：`worker/src/` 内集中常量 + 失败分类码（页面结构变化/风控/超时/字段缺失）。

## 4. 风控与限速备忘

- 本轮多次真实访问（搜索页 + 2 个主页）未触发风控；但必须保守限速（如主页串行访问 + 间隔 1.5–3s），出现验证码/安全验证立即停止并记 `restricted`。
- 不得自动绕过验证码、设备校验或频控。
