# T02｜技术方案与 API 契约

> 状态：进行中  
> 创建日期：2026-08-15  
> 产品基线：`03-交付物/01-产品文档/01-current/媒介助手_MVP_PRD.md`

## 任务目标

在不改变已确认 MVP 范围和 Figma UI 的前提下，产出可直接指导 Vibe Coding 的技术方案与前后端 API 契约。

## 工作顺序

1. 编写技术方案草案，明确架构、数据、鉴权、异步任务、小红书 PoC、AI Workflow、RAG、安全、测试和实施顺序。
2. 用户评审并确认技术方案。
3. 基于确认后的方案编写 OpenAPI 3.1 API 契约和共享数据 Schema。
4. 进入后端实现，第一验证门为小红书扫码登录及真实数据链路 PoC。

## 验收标准

- 与当前 PRD、Figma UI 和已确认决策一致。
- 清楚区分已确认方案、待确认默认值和必须经过 PoC 验证的假设。
- AI Workflow 包含输入、处理、结构化输出、异常、版本、成本与 Eval 设计，不记录模型思维过程。
- 后续可直接据此编写 API 契约、数据库迁移和开发任务。
